¡Bienvenido al Templo del Fuego! Este proyecto es un conversor de temperatura temático inspirado en la serie **Avatar: El último maestro del aire**. Permite a los usuarios transformar grados Celsius a Fahrenheit y Kelvin con una interfaz dinámica y validaciones en tiempo real.

## 📋 Características

- **Validación de Datos:** El programa identifica si el valor ingresado es numérico. Si no lo es, muestra un mensaje de error y permite reintentar.
- **Conversiones Precisas:**
  - **Fahrenheit:** Utiliza la fórmula (C * 9/5) + 32.
  - **Kelvin:** Precisión digna de un nómada aire (C + 273.15).
- **Interfaz Temática:** Diseño responsivo utilizando **Bootstrap 5** con colores y fondos alusivos a la Nación del Fuego.
- **Salida Dual:** Los resultados se muestran tanto en el DOM (interfaz gráfica) como en la consola del navegador.

## 🚀 Tecnologías Utilizadas

- **HTML5:** Estructura semántica del sitio.
- **CSS3:** Estilos personalizados, gradientes y manejo de imagen de fondo.
- **JavaScript (ES6):** Lógica de conversión, manipulación del DOM y validaciones.
- **Bootstrap 5:** Framework para el diseño responsivo y componentes de tarjetas.
